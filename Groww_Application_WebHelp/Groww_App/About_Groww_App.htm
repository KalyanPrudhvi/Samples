About Groww App

Groww App is the Online trading application which we can use in mobile app version and along with the web version.

The interface of the App is very easy to understand and it made one in all types of investment platforms.

This application allows us to invest on Equity stocks, Mutual funds, IPO, Gold, and Fixed Deposits.
