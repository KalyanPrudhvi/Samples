# Uptime Kuma documentation sample

This technical sample contains a few short documentation on Uptime Kuma, an open-source tool for monitoring websites, APIs, and services.

I wrote this sample to show how I approach technical documentation:

- Start with what the reader needs to do.
- Explain only what is necessary.
- Test the steps before publishing them.
- Keep the structure simple and easy to scan.

## Why Uptime Kuma?

Uptime Kuma is simple enough to run locally, but it still involves real technical concepts: HTTP checks, response times, heartbeat intervals, retries, notifications, and status pages. That makes it a useful subject for task-based documentation.

## How to use these files

The files are written in Markdown and can be viewed directly in GitHub. They follow a Docs-as-Code approach, so they can be reviewed through pull requests, updated in branches, and published through a documentation pipeline.
